# Matrix Operations Calculator

This project is a simple Python-based calculator for matrix operations using NumPy.

## Features:
- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose
- Matrix Determinant
- Matrix Inverse
- Eigenvalues and Eigenvectors
- Solve Linear Equations

## How to Run:
1. Install dependencies: `pip install numpy`
2. Run the script: 'python matrixcalc.py'
